# Release 9.15: v915 reference adopted

**Confidential — Sustantix.**

This release moves the product from the v732 reference to **v915** (`AIP_v915.html` + `AIP_v915.xlsx`). The runtime was re-extracted with the same pipeline. It is proven identical to v915 on every screen: 29 / 29 match exactly and the page raises zero errors.

## What changed in the experience

| Area | v732 | v915 |
|---|---|---|
| Landing | Portfolio Intelligence | **Operations Hub**: a post-login landing layer with site map, 24-month trends, forecast, predictive risk and "What requires attention now". *Skip to workspace* enters the app, and a top-bar Hub button returns to it. |
| New screen | — | **Action & Workflow Management**: Workflow Overview, Workflow Definitions, Action Register and Audit Trail. Licensed under *Platform Core*. |
| Asset scope | Solar only | Solar plus **BESS** (system, container, PCS, MV transformer, EMS), PV module and array level, backup DG and plant auxiliaries. |
| Reworked tabs | — | Operational Twin (Inverters, 3D Plant View), Maintenance Spares (Demand Intelligence, Availability & Risk, Optimize & Recommend, Governance & Handoff) and Reliability Engineering (Reliability Analytics), plus content revisions across all 27 screens that carry over from v732. |
| Runtime errors | ~250 console errors | **0** |
| Packaging | Single 65 MB HTML | gzip container (16 MB) that expands to an 80 MB app. The extractor unwraps it automatically. |

## Data contract

- **New domains:** Battery Energy Storage (15 sheets), PV Module Register (8), Asset Master & Engineering (Sites, Asset Master, Inverter configuration and telemetry, Engineering Reference Taxonomy, Graph Entities / Relationships), AI Vision & Inspection, Event Root Cause cases and evidence, the full RCM chain, Forecast runs / weather / settings, Spare Parts Master and Inventory Balance, and PM Plans.
- **Extended sheets:** Work Orders, Warranty Register and Claims, MSI Part Master, Risk Queue, Twin Engineering Parameters (tracker, IAM, bifaciality and thermal-model parameters), SUS_* provenance columns, and VE Rate Config.
- **Business keys** now come from the runtime's own import rules (`APM_SHEET_RULES`) where declared; for example, *Vision Work Order Link* is keyed on Finding + Work Order. The seed and provisioning CLIs read the committed registry, not a fresh inference.
- **No live database needs migrating.** Nothing is deployed yet, so the Supabase data-model migration and the Dataverse payloads were regenerated in place.
