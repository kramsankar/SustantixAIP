# Runtime catalogue

Generated by `pnpm --filter @sustantix/schema runtime:catalogue`; do not edit by hand.

The runtime's 36 tenant datasets hold 764 tables. Each is held once, by name:

- **241 tables read 105 governed sheets.** They are copies of a governed workbook sheet, so they are not stored again: the dataset reads the governed sheet (its own columns, in its order), and edits made to the governed tables reach every screen.
- **The other 523 tables are 229 catalogue sheets** in `aip.runtime_sheet`: each distinct table once, whichever datasets carry it. 6 of them hold a family of like lists (the same list kept per decision, per asset…) as one sheet grouped by that key.
- **Each dataset keeps only its layout** (`aip.runtime_dataset`): its structure and values, with references in place of tables.

Read any sheet in SQL: `select ordinal, group_key, record from aip.runtime_sheet_rows where sheet = '<name>' order by ordinal;`
